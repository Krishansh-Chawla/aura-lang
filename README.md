## 📜 Language Overview

Every AuraLang program must begin with `summon` as its entrypoint and conclude with `banish`. Anything outside these boundaries is ignored by the archmage.

Core Features:
- **Variables**: Declared using the `spell` keyword.
- **Console Output**: Manifested using `cast`.
- **Branching Logic**: Conditionals powered by `prophecy` (if) and `oracle` (else).
- **Loops & Flow Control**: Executed with `ritual` loops, supporting `break rune` and `next rune`.
