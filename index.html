AuraLang Documentation

AuraLang is a magical, dynamically typed toy programming language built around fantasy spells, runes, and arcane rituals.

General Structure

Every spellbook program must begin with summon as its entrypoint and conclude with banish. Anything outside these boundaries is ignored by the archmage.

This will be ignored by the compiler

summon
    // Write your magical script here
banish

Initializing Variables (spell)

Variables are declared and initialized using the spell keyword. Subsequent updates can be performed directly using the variable name.

summon
    spell energy = 50;
    spell element = "fire";
    energy = energy + 10;
banish

Printing Output (cast)

Use the cast keyword to manifest outputs onto the scrying console. You can print strings, numbers, booleans, or comma-separated sequences.

summon
    cast "Portal Opened successfully";
    spell mana = 100;
    cast mana, "units remaining";
banish

Conditionals / If-Else (prophecy & oracle)

AuraLang supports branching logic using prophecy (condition) { ... } which executes if the condition evaluates to true. The optional oracle { ... } block executes otherwise.

summon
    spell power = 85;
    prophecy (power > 90) {
        cast "High Power Surge!";
    } oracle {
        cast "Normal Power Levels.";
    }
banish

Loops / Rituals (ritual)

Statements inside a ritual (condition) { ... } block are executed repeatedly as long as the specified condition evaluates to true.

summon
    spell a = 0;
    ritual (a < 3) {
        a = a + 1;
        cast a;
    }
banish

Break & Continue (break rune & next rune)

Inside loops, you can shatter execution early using break rune or skip to the next cycle using next rune.

summon
    spell x = 0;
    ritual (x < 5) {
        x = x + 1;
        prophecy (x == 2) {
            next rune;
        }
        prophecy (x == 4) {
            break rune;
        }
        cast x;
    }
banish
